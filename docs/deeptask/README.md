## Engineering records

Deeptask-specific records live here so the repository root remains limited to standard project
entry points.

- `releases/`: versioned GitHub release notes.
- `progress/`: historical implementation and acceptance records.
- `analysis/`: root-cause investigations and architectural comparisons.
- `guides/`: maintained user and operational documentation.

Release notes are immutable after publication except for factual corrections. Progress files are
evidence of past work, not current build configuration.

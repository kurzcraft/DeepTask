# Deeptask 9.0.2

本补丁修复任务取消、继续发送和多文件读取提示中的剩余一致性问题：

- 取消后的编辑重发在原任务无法恢复时创建新任务，并保留用户消息、图片与继续选项，避免消息被吞。
- Webview 续发入口等待取消和续发准备事务，准备阶段异常会回到统一恢复边界，不再成为脱离状态机的 Promise。
- 工具失败后的下一轮继续路径保持可达，保留模型可见的错误结果与任务状态恢复。
- 多文件读取审批提示在 22 个界面语言包中统一使用 Deeptask 品牌，并增加批量读取 UI 回归测试。
- 更新中英文项目介绍、插件打包内 README、安装命令和 Marketplace 介绍页至 9.0.2。

## 验证

- 消息投递、取消恢复与 Webview 消息路由回归：69 项通过。
- 多文件读取品牌与 ChatRow UI 回归：5 项通过。
- Webview 生产构建与扩展 bundle 将由标准 10 阶段 VSIX 打包入口强制重建并审计。
- VSCodium 覆盖安装、扩展版本和 GitHub Release 资产将在打包后写入本说明与任务进度。

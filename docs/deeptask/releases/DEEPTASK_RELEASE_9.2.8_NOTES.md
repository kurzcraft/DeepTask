# Deeptask 9.2.8

## 功能与修复

- 中断恢复：子代理终态结果持久化、去重回传、取消不重启。
- 父中断保活：父代理中断不再取消仍在运行的子代理；resume 等待 inbox 落盘终态，并用最终 tool_result 替换中断占位。
- 关窗重启：子代理完成消息落盘即写父 inbox，不依赖同进程 runPromise；重启后从历史恢复子代理身份，父点继续才注入终态。
- 工作区：工具绑定隔离源码目录；兼容依赖默认复用，避免共享安装写入。
- 合并：临时树预检后发布到实际目标分支及检出目录，保留无关修改，冲突返回错误。
- 命令：超过两条物理行立即拒绝，要求改用脚本及持久日志。
- 长上下文压缩：增量续跑状态，禁止复述上一轮开场白或嵌套 Previous Conversation；15 秒本地快路径仍保留最新用户请求。

## 追加资源优化

- 辅助HTML转义缓存按UTF-16载荷估算限制总预算1MiB、单项64KiB；大文本完整返回但不驻留缓存，不裁剪历史或工具结果。
- Shiki仅预加载当前界面使用的两种主题，其余主题按需加载；保留语言/主题兼容和失败重试。
- 重叠全量状态请求合并为执行批次及共享尾批，保留最新状态、等待语义、错误传播和释放边界。
- fork子进程消除同一快照的成对重复IPC；不删除独立状态事件和父端控制流程。
- 工作区领取与释放使用原子变更和owner校验，避免并发覆盖及旧实例释放新实例占用。
- 只去除宿主生成的重复进度/命令规则、紧凑化MCP schema空白；不删用户规则，不降低上下文窗口或修改压缩阈值。

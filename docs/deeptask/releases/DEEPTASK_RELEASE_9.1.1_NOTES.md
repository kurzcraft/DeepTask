# Deeptask 9.1.1

## 修复

- 自动折叠只在打开 VSCodium 窗口时执行一次，之后开新对话不再把其他文件夹重新折叠。
- 运行中的对话显示径向转动条并自动展开所在文件夹；后台任务完成后不跳转当前对话，只给未查看的对话加绿点。
- 有任务在跑时，其他对话不再被后台流式状态闪成空初始界面；并行新建任务后不再 invoke `newChat`。
- 在 VSCodium 窗口打开文件夹时，左侧栏立即显示该文件夹下的对话，展开当前文件夹并折叠未打开的文件夹。
- 历史记录单击即可打开任务，左侧栏高亮对应对话；已在运行的任务不会被停掉，历史任务可并行。
- 新增对话与 agent 工作区迁移后立即广播到左侧栏，对话写入串行化，避免广播覆盖未落盘的内存状态。
- 磁盘上删除 git worktree 后，左侧栏立即 prune 掉对应工作区；并对 `.kilocode/worktrees/*` 监听创建/删除。
- 对话中点击用户消息跳转条按消息时间戳钉住目标，流式高度变化时反复校正，避免停在过程位置；到底后才恢复自动下滚。
- 更新中英文 README、扩展包内 Marketplace 介绍页、安装命令和版本信息至 9.1.1。

## 安装

```bash
codium --install-extension ./deeptask-9.1.1.vsix --force
```

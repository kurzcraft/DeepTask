# Deeptask 9.0.0

本版本收紧长任务的交互契约，并恢复 Linux 桌面的完成反馈：

- 在 Linux 上通过宿主音频播放器可靠播放通知与任务事件音效，播放器不可用时保留可诊断日志且不阻断任务。
- 自动批准已开启且提问权限关闭时，不再向模型暴露提问工具，避免无人值守任务因追问而停滞。
- 任务进度 Markdown 文件成为唯一持久清单；模型负责创建和实时更新该文件，宿主会在系统提示中提供精确宿主任务 ID，并仅在空目录首次创建时提供安全兜底。
- 保留任意层级的 Markdown 待办结构，并在文件变化后自动投影到内置待办列表。
- 使用 `deeptask-task-id` 标记唯一识别任务文件，防止不同任务实例误认领其他清单；修复首次创建时模型因看不到宿主 ID 而必须第二次修改 marker 的问题。
- 修复完成消息续接路径在 ES2022 目标下的类型兼容性。

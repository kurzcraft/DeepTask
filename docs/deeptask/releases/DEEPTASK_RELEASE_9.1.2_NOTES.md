# Deeptask 9.1.2

- 编辑用户消息后立即落盘新内容、清空后续轮次并直接发送；编辑助手消息后插入处于编辑态的用户消息「继续」。
- 左侧栏绿点仅在绿色总结完成后、且该对话非焦点时出现。
- 新运行任务绑定为可点击会话行，不再显示原始任务 ID；同一会话的占位行与绑定行去重。
- 删除历史记录后左侧文件夹栏同步移除对应会话。
- 新窗口把 Deeptask 留在左侧主栏，关闭右侧多余辅助视图，并按窗口宽度把面板右缘对齐中心线。
- z.ai 自动刷新最新模型目录，并保持真实推理档位。
- 更新中英文 README、扩展包内 Marketplace 介绍页、安装命令和版本信息至 9.1.2。

安装：

```bash
codium --install-extension ./deeptask-9.1.2.vsix --force
```

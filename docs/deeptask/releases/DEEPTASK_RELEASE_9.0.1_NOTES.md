# Deeptask 9.0.1

本补丁修复工具调用失败后任务可能无提示卡死的问题：

- 将内置工具与原生 MCP 工具的意外异常统一收敛到助手消息分发边界。
- 对原生协议补齐唯一的 `tool_result` 错误结果，让模型收到可操作的失败信息并继续下一轮，而不是留下孤立工具调用。
- 无论工具执行、错误显示还是二次错误呈现是否失败，均释放消息呈现锁并完成当前内容索引推进，避免任务停在不可发送、不可继续的状态。
- 保留用户主动取消的终止语义；仅把非取消的工具故障转化为可恢复错误。
- 更新中英文项目介绍、插件打包内 README 和安装命令至 9.0.1。

- Task 回归：123 项通过，4 项跳过。

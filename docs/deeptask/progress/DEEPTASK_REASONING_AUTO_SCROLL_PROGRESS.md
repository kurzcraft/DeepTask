## 当前决策

- 仅由明确的用户向上滚动手势解除自动跟随，不能由内容增长触发的 scroll/atBottom 事件解除。
- 用户回到底部或点击“滚到底部”后恢复持续跟随。
- 流式消息内部高度变化与 Markdown 异步排版必须触发底部纠偏，不能只依赖列表长度变化。

## 验收边界

- Agent 推理持续增长时始终跟随到底部。
- 用户主动向上滚动后不强制拉回。
- 用户回到底部后自动恢复跟随。
- 不引入定时轮询；卸载时释放观察器和动画帧。
